# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Security and privacy are core pillars of TELYRA.

If you believe you have discovered a security vulnerability or sensitive information leakage:
1. Please do not open a public issue.
2. Email directly to: `security@b4.lol` or open a private GitHub Security Advisory at:
   https://github.com/b4lol/telyra-releases/security/advisories/new

We acknowledge all legitimate security reports within 24 hours and provide rapid patches for verified issues.
